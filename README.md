# Пакет для управления базой данных

Программа поддерживает создание, просмотр и удаление таблиц. Информация о таблицах хранится в файле `db_meta.json`.

## Команды

| Команда                                | Описание                       |
|----------------------------------------|--------------------------------|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу                |
| `list_tables`                          | Показать список всех таблиц    |
| `drop_table <имя>`                     | Удалить таблицу                |
| `help`                                 | Показать справочную информацию |
| `exit`                                 | Завершить работу программы     |

Поддерживаемые типы данных: `int`, `str`, `bool`.

## Запуск программы

Программа запускается командой:
```bash
database
```

Создание таблицы `users`:
```text
create_table users ID:int name:str age:int is_active:bool
```

Просмотр списка таблиц:
```text
list_tables
```

Удаление таблицы:
```text
drop_table users
```

Вывод справки:
```text
help
```

Завершение работы:
```text
exit
```

## CRUD-операции

После создания таблицы можно выполнять операции с записями.

| Команда | Описание |
|---------|----------|
| `insert into <имя_таблицы> values (...)` | Добавить запись |
| `select from <имя_таблицы>` | Показать все записи |
| `select from <имя_таблицы> where <столбец> = <значение>` | Найти записи по условию |
| `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` | Обновить записи |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить записи |
| `info <имя_таблицы>` | Показать информацию о таблице |

### Примеры

Добавление записи:

```text
insert into users values ("Sergei", 28, true)
```

Просмотр всех записей:

```text
select from users
```

Поиск по условию:

```text
select from users where age = 28
```

Обновление записи:

```text
update users set age = 29 where name = "Sergei"
```

Удаление записи:

```text
delete from users where ID = 1
```

Информация о таблице:

```text
info users
```
